# Dashboard review images

Each of the eight dashboards has a 1440 x 900 desktop capture, a full-page 390px phone capture, a 1920 x 1080 presentation capture and a one-page landscape PDF. `learning-export.png` demonstrates the whole-view image export. `results.json` records the browser checks.

Generated by `python test_dashboard.py` against the public bundle. PDFs are checked for content as well as page count. Screenshots show published source data and the default configuration; unavailable choices remain labelled.
