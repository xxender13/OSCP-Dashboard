# Dashboard review images

Each of the eight dashboards has a 1440 x 900 desktop capture, a full-page 390px phone capture, a 1920 x 1080 presentation capture and a landscape PDF (two summary pages for the expanded support dashboard; one for other dashboards). `learning-export.png` demonstrates the whole-view image export. `results.json` records the browser checks.

Generated by `python test_dashboard.py` against the public bundle. PDFs are checked for content as well as page count. Screenshots show published source data and the default configuration; unavailable choices remain labelled.

Community engagement section captures are also included at 1440px and 390px. The support dashboard keeps source types separate and prints a monthly timeline summary; full activity details are available through CSV.
