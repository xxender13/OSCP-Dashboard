# Configured Home and eight dashboard frames

November 14, 2026 - `redesign-three-levels` - PR #1

This amendment supersedes the earlier layout descriptions below. The original numerical baseline, workbook files and calculation/status rules are preserved.

- **Renamed and moved:** Overview becomes Home; Programs becomes OSCP Sponsorships, including navigation, headings and hashes. Old links redirect. The slim header keeps search; Presentation view moves to the footer. Home replaces the former Overview analytical canvas and contains the exact introduction, four-level guide, six tiles, six-school scorecard plus separate Missouri row, seven directory cards and descriptive caption. The separate date strip and duplicate headline tiles are removed.
- **Single configuration:** `config/dashboards.json` drives all eight navigation items, titles, questions, Home cards and applicable filters. The local report reads the same definitions. Schools, Sponsorships, Explore Data and About now use the same title, four-level key, filters, panel metadata and export frame as the analytical dashboards.
- **Defaults:** all schools, school level, 2025, alphabetical order and Missouri on; Students starts with Black students, Learning with both subjects, Total student group and grade 3; the enrollment bridge is initially shown. Schools starts with all cities and no search. Sponsorships defaults to all program types, all fiscal years and confirmed items only. Its School and Fiscal year controls are disabled because confirmed school-linked and fiscal-year inputs are unavailable. No request-log entries become public events or awards. Explore Data starts with enrollment history and retains report-specific filters.
- **Learning:** Student group and Grade/course controls use existing assessment and matched-grade data. Choices without published results remain visible, disabled and labelled Not published. Pooled MAP values are the explicit partial-coverage exception: the label computes reporting-school counts and reportable-test coverage from source counts, including the rounded percentage. It accompanies Home tiles, scorecard columns, Learning tiles, captions and exports. No suppressed performance level is reconstructed.
- **Students:** Asian, American Indian and Pacific Islander categories are added from existing source columns. Published race shares remain unnormalized. Demographic pools still require all six compatible reported pairs; IEP remains school-specific. Missing years remain gaps, with school join-year context.
- **Sizing and interactions:** centred 1240px container, 24px sides (16px phones), 360/320/300px panel tokens, two desktop columns and one below 900px. ResizeObserver maintains charts and sticky offsets. Navigation/filter/dropdown layers use 40/30/50. Phones have static filter bars; dropdowns remain visible. Selected long school names abbreviate with full tooltips. Table views, per-panel CSV/PNG, whole-view PNG, reset, active chips, URL state and value sorting are shared.
- **Presentation and print:** Home is slide one, followed by the other seven dashboards. Each dashboard prints on one landscape page; print checks validate page content as well as page count. Exports use vendored libraries and no CDN. Equivalent JavaScript escapes preserve library behavior while meeting the strict public-content scan. Embedding and deferred data packets remain supported.
- **Local report and safety:** `python build.py --report` generates an ignored landscape Word report with page fields, dashboard/filter/panel sections, source-derived readiness, reconciliation and numbered requests. Roles replace people in the generator. Existing tracked internal material is inventoried locally and retained as requested. No generated report enters `dist/` or the commit.
- **Validation:** unchanged numerical hash and workbook-hash checks; configuration/report parity, source slice comparisons, public-content scan and browser checks across 320, 375, 390, 768, 1024, 1440 and 1920px. Default-view numeric text is checked against public source values, displayed rounding, source collection sizes and documented percent-axis endpoints; MAP coverage is independently recomputed. Checks cover suppression, controls, Home links, redirects/search/history, sticky anchors, dropdowns, geometry, CSV/PNG, PDF content, presentation, embedding and chart fallback. Current screenshots are in `docs/dashboard-screenshots/`.

## Earlier amendments

# Compact analytical canvases

November 14, 2026 · amendment on `redesign-three-levels` · PR #1

The four analytical tabs now use a title band, shared filters, a compact KPI strip, a two-by-two panel grid and a definitions band. Schools, Programs, the detailed report topics and About retain their previous content. The original numerical hash, workbooks, source values and internal status decisions remain unchanged.

- **Shared structure:** new `analytics.js` supplies filter state, KPI strips, panels, chart creation, school colours and markers, exports, and presentation preparation. `canvas.css` defines the compact layout. The main page and `explorer.html` load the same components. The original six headline tiles appear once, in Overview’s strip; the outer tiles remain on the other non-analytic tabs.
- **Overview:** enrollment, complete-year stacked enrollment history, reading/math together and growth designation counts form four panels. Six headline tiles lead the canvas. Five things to know, the school scorecard and the Kansas City/St. Louis split remain in a collapsed disclosure below it. The enrollment headline is still 3,953; the city counts remain 3,247 and 706.
- **Students:** eight compact tiles show enrollment, lunch, Black, Hispanic, White, Multiracial, English learners and students with IEPs. The four panels contain the selected student group, historical measures, published race categories, and a switch between enrollment history and the population bridge. Default Black remains 1,255 / 3,913 = 32.07%; lunch remains 2,330 / 3,816 = 61.06%; the bridge remains 3,953 + 197 = 4,150. Historical year selections update the snapshot and end the time charts at that year; preliminary enrollment is kept distinct.
- **Learning:** reading, math, exact-grade comparisons and four published performance levels form four panels. Both subjects can be viewed together; a grade control uses the existing matched-grade slices. Pooled counts remain the three published schools: 823 / 1,753 = 46.95% reading and 877 / 1,765 = 49.69% math, with “3 of 6” explicit. Missouri remains 44.00% and 42.63%, labelled all tested grades outside the exact-grade panel. All four performance levels must be published before a stacked bar is drawn.
- **Growth:** designation counts, a school-building heat-table, earned/possible points and Target shares versus Missouri form four panels. Counts remain 7 of 13 and 5 of 13; Missouri remains 24.99% and 24.67%; 13 of 14 school buildings are eligible. The PK–K school building is labelled Not tested. Growth outcomes remain school-building measures when grouped or filtered by school; no school-wide designation is invented.
- **Filter behavior:** one filter-bar component serves the four canvases. Schools / School buildings is a two-option control; Show Missouri is a separate default-on toggle. School input accepts accents or unaccented names. Year is offered only on the historic Students view; other source years are fixed chips. Subject/measure, grade, sort and bridge/trend selections are stored after the hash. Reset restores defaults. Removable chips expose active filters. Clicking a school bar or school legend item toggles its school selection; school-building selections stay within the chosen school.
- **Panel behavior:** compact title bars carry level and year chips. The ⋯ menu provides Download PNG, Download CSV and View as table. Charts have a one-sentence summary and level/year/source/reporting captions. An empty selection keeps its panel and says “No published results for this selection”. Detailed Explorer reports use the same title/menu/table presentation and filter styling; they retain all six topics and their existing measures.
- **Encodings:** each school keeps its colour and marker identity across charts; school buildings and stacked categories use its shade family. Designation words and border styles supplement the growth colours. Percentage axes remain 0–100; bars start at zero. Missouri uses dashed grey references or distinct comparison rows, never school bars. Tooltips include level, year and available counts/denominators. A missing published denominator is stated rather than reconstructed. Sort starts alphabetically; value sorting keeps labels aligned with their data.
- **Honest gaps:** incomplete early-year coverage cannot form an honest complete-cohort area. The area therefore gaps years without every selected school, while its table retains earlier published values and reporting counts. Join-year guides and markers identify historical context. Race bars retain published percentages, unfilled space and unpublished-category lists; they are not normalized and no remainder is inferred. Demographic pooling requires complete compatible count/denominator pairs; IEP stays single-school only. These are the closest honest versions of the requested charts using existing data.
- **Public labels:** the previous display labels Withheld by DESE / Not applicable are replaced by Not published / Not tested / Not available. Internal statuses are unchanged. No internal names, work notes or unconfirmed program values enter the public bundle, and no attendance data or external organisation branding is added.
- **Sharing:** Export this view captures the complete canvas through vendored html2canvas 1.4.1; Chart.js remains self-hosted. Library licences are retained. Equivalent Unicode escapes in minified library identifiers keep the strict public-content scan passing without changing JavaScript behavior. Focus view hides the outer page header. Presentation uses each analytical canvas as one slide. Landscape print gives each canvas its own page, and the existing embed height protocol remains supported.
- **Performance:** canvas history and grade slices load only as needed; Explorer packets still wait for Explore Data. Charts render only for the opened view, with cached slices used on filter changes. `summary.json` remains below 400 KB. The responsive grid is two columns at desktop widths and one column below 900px; tables scroll within their panels.
- **Validation:** the original regression hash and source-workbook hash checks remain. New slice tests compare historical values, counts, statuses and exact-grade results with the unchanged internal payload. Browser tests cover the four default desktop layouts, URL/filter round-trips, strict demographic pooling, gaps and unpublished levels, school clicks, reference toggles, tooltips, CSV/PNG and full-canvas PNG, report menus, keyboard/search/legacy routes, mobile widths, presentation, one-canvas PDFs, embedding and blocked chart loading. New screenshots and export examples are under `docs/analytic-screenshots/`.

## Earlier dashboard presentation and navigation changes

November 14, 2026 · `redesign-three-levels` · PR #1

Existing calculations, numerical baseline, source workbooks and status decisions are preserved. This release changes public packaging, labels and placement.

- **Header:** one slim row with SLU mark, office name, “Charter School Partnerships Dashboard”, search and Presentation view. Edition badge, large introduction and previous navigation are removed. Dates move below the tiles and into About.
- **Six tiles:** Students enrolled (3,953), School communities (6 / 14, with 12 street addresses), Lunch eligibility (61.06%; 2,330 / 3,816), Reading (46.95%; 823 / 1,753), Math (49.69%; 877 / 1,765) and Reading growth (7 of 13). Each opens and highlights its section. The causal limitation appears below the tiles and once in About.
- **Navigation:** eight accessible tabs replace the long page: Overview, Schools, Students, Learning, Growth, Programs, Explore Data, About the data. Each has an introduction, jump chips and breadcrumb. The tab row sticks while scrolling, supports arrow/Home/End keys and scrolls horizontally on phones.
- **Overview:** five generated facts, compact six-school scorecard with separate Missouri row, computed Kansas City / St. Louis split (3,247 / 706 students).
- **Schools:** six profiles with city, opening year, SLU join year, grades, school building count and enrollment. Directory has 14 rows grouped by school, grades and address, with search and city filters. Wording: “14 school buildings at 12 street addresses”.
- **Students:** enrollment, population bridge (3,953 + 197 = 4,150), 3,913 race population, 3,816 January membership, every reported race/ethnicity category, lunch, English learners and students with IEPs. Black enrollment (1,255 / 3,913 = 32.07%) remains in student groups.
- **Learning:** reading and math by school or school building, published ranges, pooled counts inside collapsed guidance and a same-grade Explorer link. Missouri 44.00% / 42.63% is a dashed reference rather than an equal bar.
- **Growth:** 7 of 13 reading and 5 of 13 math school buildings lead, followed by Missouri 24.99% / 24.67%. A short Target explanation replaces repeated technical paragraphs.
- **Programs:** one “details coming soon” card per unconfirmed area: scholarships, events, partnership reach and OSCP support. Only existing confirmed input rows can appear.
- **Explore Data:** six report sub-tabs: Enrollment history, Student groups, Reading and math, Grade comparison, Growth, Directory. Each has filters, Reset filters, CSV and PNG. One report is visible at a time. `explorer.html` serves the same component; detailed packets load only on entering Explore Data.
- **About:** glossary, years, DESE links, chart guidance, descriptive limits and citation instructions. Internal reports and former engineering notes move to `docs/internal/`, excluded from `dist/`.
- **Levels:** Schools (blue, circle), School buildings (teal, grid), Missouri (grey, diamond). Students, Learning and Growth use two-option switches and three-level definition legends. Missouri remains beside the selected level.
- **Unavailable values:** Not published, Withheld by DESE, Not applicable. The scorecard uses Not published for unpublished MAP. Internal status values and calculation rules are unchanged.
- **Public packaging:** names, input responsibility, unfinished questions, requests, verification matrices and processing notes leave public packets. The full payload stays private for the original hash and calculation regressions.
- **Visuals:** one system font, light borders, 12px corners, 8px spacing scale, 1200px content width, larger chart labels, fewer gridlines, separate Missouri reference and tables that scroll within cards.
- **Search and links:** accent/case-insensitive matching, `/`, arrows, Enter, Escape; schools open profiles and school buildings open directory rows. Names link to profiles. Old section bookmarks redirect; tab/section hashes support browser history.
- **Sharing:** presentation begins with tiles then section panels; arrows navigate and Escape exits. Print expands sections in order, landscape, one section per page. Embed hides header/footer and posts height messages. EMBED.md contains public instructions.
- **Loading and fallback:** six skeleton tiles, self-hosted Chart.js and usable tables if chart loading is blocked. One vendor DOM property uses an equivalent Unicode escape to meet the strict public-text scan without changing behavior.
